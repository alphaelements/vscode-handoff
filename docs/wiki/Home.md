# Handoff VSCode Extension — Wiki

Handoff is a VS Code extension that visualizes and manages project data created by [handoff-mcp](https://github.com/alphaelements/handoff-mcp). It gives you a full project management suite — task explorer, dashboard, Gantt chart, metrics, time tracking, and session history — without leaving your editor.

This wiki covers everything you need to get started and make the most of each feature.

## Contents

- [Getting Started](Getting-Started) — Installation, prerequisites, and your first run
- [Task Explorer](Task-Explorer) — Sidebar tree view with filtering, sorting, and status management
- [Task Detail](Task-Detail) — Done-criteria checklist, schedule editing, dependencies, and time tracking
- [Dashboard](Dashboard) — Project overview with KPI cards, Kanban board, effort budget, and activity feed
- [Gantt Chart](Gantt-Chart) — Interactive timeline with drag-to-reschedule, milestones, and compare mode
- [Metrics](Metrics) — Effort tracking, velocity trends, budget allocation, and completion analytics
- [Time Tracker](Time-Tracker) — Automatic time tracking with idle detection and persistence
- [Session Browser](Session-Browser) — Browse AI session history, decisions, blockers, and handoff notes
- [Team Panel](Team-Panel) — Member cards, capacity summary, task assignments, and workload overview
- [Configuration](Configuration) — Extension settings, `config.toml` reference, and locale options
- [FAQ](FAQ) — Common questions and troubleshooting
